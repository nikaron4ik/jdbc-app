# JDBC Courses Application

Консольное приложение на JDBC для управления курсами, преподавателями, студентами и записями на курсы.

## Таблицы
- `teachers` — преподаватели (1:N с courses)
- `courses` — курсы
- `students` — студенты
- `enrollments` — запись студента на курс (N:M между students и courses)

## Запуск MySQL при помощи Docker
```bash
docker compose up -d
```

## Реализованные возможности
- CRUD-операции для каждой таблицы
- Использование SQL-запросов с JOIN для вывода информации из нескольких таблиц
- Обработка ошибок пользовательского ввода
